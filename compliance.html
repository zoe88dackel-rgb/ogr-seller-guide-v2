合规与认证

先审 SKU，再备货

是否需要 EAC，由平台审核团队和清关行根据你提交的信息和照片决定。不确定的，先预审，不要先发货。

正规 EAC 要寄样实测

样品寄到俄罗斯实验室，通常 5 件，空运 7–10 天，检测 2–4 周，多数 1 个月内出证。

证书必须 FGIS 可查

申请人须是俄罗斯法人；HS Code、制造商、型号范围要和实际发货一致。

1Д 方案要当心

1Д 方案、实验室在 EAEU 境内、又查不到样品进口记录，证书不被接受。

CoC 与 DoC

法律效力相同，按风险等级区分。服装常用 DoC TP TC 017，玩具 CoC TP TC 008，电子 CoC TP TC 004+020。

有效期与年审

最长 5 年，每年要做年审；KG、KZ 签发的证书 2026 年起审核更严。

诚信标签

不再拦截 SKU 添加，但依法需要 Data Matrix 的商品仍要贴，且要能扫描。

常见被拒

这十种情况，最容易被打回。

品牌限制

  • 授权须写明可在俄罗斯 Ozon 销售，缺授权可被索赔 GMV 两倍
  • TROIS 清单且不在平行进口清单的品牌不能发
  • 在俄罗斯有诉讼记录、平台有活跃版权方的品牌不能发
  • 跨境店认可过的品牌文件，OGR 不能直接沿用

识别不靠谱服务商

  • 「不用寄样」「3 天出证」
  • 报价特别低
  • 「HS Code 差不多就行」
  • 说不出适用哪个 TP TC 法规
